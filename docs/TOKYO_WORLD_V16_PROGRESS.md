# Tokyo World 1.6 — Expert i progresja
Etapy questów: Early / Mid / Late-Endgame. Zachowano ID questów i zależności, powiększono ikony oraz banery i wymuszono widoczność linii.
Nowe receptury w kubejs/server_scripts/tokyo_world_expert_16.js. Dodano osobne profile tokyo-next-tech, tokyo-next-adventure, performance-fps, visual-extras, visual-shaders.
Dodatki graficzne i shadery domyślnie wyłączone; Oculus/Complementary można aktywować osobno.
W przypadku nowych modów eksploracyjnych generowanie struktur następuje w nowych chunkach.
Repozytorium jest prywatne: samoczynne aktualizacje EXE z GitHub Releases wymagają dostępu/tokena, którego nie wolno zaszywać w aplikacji.
